Dernière version

⚠️ Windows affiche un écran bleu ?

C'est normal : le launcher n'est pas encore signé numériquement, donc Windows demande une confirmation la première fois. Il y a deux façons de continuer :

  1. Méthode 1 : clic droit sur le fichier téléchargé, Propriétés, coche Débloquer en bas de la fenêtre, OK, puis lance le fichier.
— ou —
  1. Méthode 2 : lance le fichier, clique sur Informations complémentaires, puis sur Exécuter quand même.

Et ensuite ?

Cet écran n'apparaît qu'une seule fois, à la première installation. Les mises à jour se font ensuite toutes seules, avec le bouton METTRE À JOUR du launcher.

Tu préfères une installation sans aucun avertissement ? Le launcher est aussi disponible sur le Microsoft Store.
